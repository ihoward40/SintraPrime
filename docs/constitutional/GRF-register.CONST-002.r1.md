## Purpose

This register records all Governance Review Findings (GRFs) raised against CONST-002
during its review cycle. A GRF is a formally tracked observation, concern, or defect
identified during governance review.

GRFs do not modify the artifact under review. Every identified issue is captured here,
preserving document stability while the review proceeds.

---

## Disposition Codes

| Code | Meaning |
|---|---|
| OPEN | Finding is recorded and awaiting disposition |
| APPROVE | Finding is accepted; artifact advances without change |
| RESOLVE | Finding requires a change before advancement |
| DEFER | Finding is deferred to a later review cycle |
| CLOSE-NF | Finding is closed as Not a Finding |

---

## Severity Codes

| Code | Meaning |
|---|---|
| BLOCKING | Must be resolved before C2 advancement |
| NON-BLOCKING | May be resolved after C2 advancement |
| ADVISORY | Informational; no resolution required |
