# ADR-0001 — Tier 1 Constitutional Freeze

## Status

Adopted

## Decision

Founding Week enters a documentation freeze for Tier 1 constitutional governance work.

## Rationale

- Governance quality is no longer the primary bottleneck.
- Constitutional review and operational evidence now provide more value than framework expansion.
- Freeze discipline reduces architecture drift while Track B is observed in production.

## Consequences

- Tier 1 work proceeds in locked order: `CONST-002` → `CONST-003` → `CONST-004` → cross-validation → ratification.
- Track B remains in production-validation watch during the observation window.
- Changes are limited to defect correction, constitutional conflict resolution, traceability repair, and operational blocker removal.
- No new governance model, dashboard family, or implementation scope is introduced under this ADR.
