# Hierarchy and Command Authority Guidance (v1)

## Purpose

Clarify constitutional/governance hierarchy and the placement of Command Authority.

## Governance hierarchy

1. Constitutional artifacts (Tier 1)
2. Governance decisions and ADR controls
3. Implementation governance documents
4. Operational implementation artifacts

## Command Authority position

Command Authority is an implementation governance document.

- It is governed by constitutional and governance layers.
- It is not a peer authority to constitutional artifacts.
- It cannot supersede constitutional requirements, ADR freeze constraints, or GRF dispositions.
