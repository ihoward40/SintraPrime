# ADR-0002 — Constitutional Review Protocol v1

STATUS: Approved
DATE: 2026-07-03

## Locked review sequence

When a Tier 1 constitutional artifact is submitted, review it in this order:

1. Completeness Review
2. Constitutional Conformance
3. Structural Integrity
4. Traceability
5. Governability
6. GRF Classification
7. Formal Disposition

## Review guardrails

- Do not introduce new governance models during review unless a real constitutional or traceability defect requires it.
- Record any defect as a GRF entry tied to the artifact under review.
- Treat `CONST-002` as the current critical artifact for the next submission cycle.
- On `CONST-002` submission, begin this sequence without reopening scope.
