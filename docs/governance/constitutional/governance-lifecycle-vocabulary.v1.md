# Governance Artifact Lifecycle Vocabulary (v1)

This vocabulary is normative for governance artifacts and dashboards.

## Standard Lifecycle States

1. **Draft** — Initial authoring state; content is under preparation and not review-complete.
2. **Review** — Active governance review state; content is under formal assessment and may receive findings.
3. **Approved** — Review accepted by designated authority with no blocking findings for advancement.
4. **Ratified** — Formally adopted as part of the governance baseline by ratification authority.
5. **Enforced** — Ratified requirements are actively applied through delegated controls and compliance checks.
6. **Archived** — Historical retention state; artifact is superseded or retired and no longer current authority.

## Usage Rules

- Use only these six lifecycle terms in governance status tables, dashboards, and constitutional tracking notes.
- Avoid synonyms (for example: "active", "candidate", "final", "complete") in lifecycle fields.
- Pair lifecycle state with maturity markers (for example: `C0`, `C1`, `C2`) when both are needed.
