# Governance Lifecycle Vocabulary (v1)

## Purpose

Define canonical lifecycle states for formal governance status communication.

## Canonical lifecycle states

Use only these states in formal governance status records:

1. **Draft**
2. **Review**
3. **Approved**
4. **Ratified**
5. **Enforced**
6. **Archived**

## Usage rule

- Non-canonical state wording must not be used for formal governance status communication.
- Supplemental commentary is allowed, but lifecycle state fields must use canonical values only.
