# Governance Lifecycle Vocabulary v1

## Artifact lifecycle states

| State | Meaning |
| --- | --- |
| Draft | Under active preparation; not submitted for formal review. |
| Review | Submitted for formal evaluation against defined gates. |
| Approved | Accepted by the designated reviewer for advancement. |
| Ratified | Formally accepted by the Founder as a constitutional decision. |
| Enforced | Compliance monitoring or runtime controls are activated by Hermes. |
| Archived | Superseded but retained for historical traceability. |

## Maturity codes

| Code | Meaning |
| --- | --- |
| C0 | Not started |
| C1 | Initial draft or staging package exists |
| C2 | Internally consistent and reviewable |
| C3 | Review-complete and dispositioned |
| C4 | Ratified baseline established |
| C5 | Enforced in operational practice |
| C6 | Sustained with audit evidence over time |

## Vocabulary rules

- Use **Ratified** for constitutional artifacts accepted by the Founder.
- Use **Enforced** for governance controls activated and monitored by Hermes.
- Use **Approved** for interim review outcomes that are not yet ratified.
- Treat **Command Authority** as an implementation document governed by constitutional and governance layers, not as a peer authority layer.

## Freeze rule

During Founding Week documentation freeze, terminology may be clarified for consistency, but no new governance layer, review model, or operational scope may be introduced without a documented defect-based exception.
