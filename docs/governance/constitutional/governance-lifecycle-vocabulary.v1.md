# Governance Lifecycle Vocabulary v1

STATUS: Approved
SCOPE: Founding Week governance communications

## Canonical lifecycle states

1. **Draft** — artifact exists but is not yet submitted for formal review.
2. **Review** — artifact is under formal evaluation against the locked review protocol.
3. **Approved** — artifact has passed review but has not yet been ratified by the Founder.
4. **Ratified** — artifact has received formal Founder approval and joins the Tier 1 baseline.
5. **Enforced** — governance controls are actively monitored or applied in operations.
6. **Archived** — artifact remains citeable but is no longer the active governing version.

## Usage rules

- Use only the canonical lifecycle states in formal governance reporting.
- Do not describe documents as "authoritative" in place of lifecycle state.
- `CONST` artifacts become **Ratified** by Founder action.
- `GOV` artifacts become **Enforced** only when operational monitoring is active.
- Command authority and implementation guidance remain subordinate to constitutional and governance layers.
