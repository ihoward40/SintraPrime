## Purpose

This register tracks all Governance Request Forms (GRFs) raised during the Round 1 governance review of CONST-002. GRF types are defined in the Constitutional Review Protocol.

| Type | Effect |
|------|--------|
| GRF-A | Blocking constitutional defect — must be resolved before Approved disposition |
| GRF-B | Structural concern requiring correction — must be addressed before Ratified |
| GRF-C | Improvement recommendation — non-blocking; may be batched post-ratification |
| GRF-D | Editorial or clarification item — non-blocking |

Only GRF-A findings block advancement from Review to Approved.
